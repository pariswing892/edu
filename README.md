# micro:bit 感應器挑戰賽

Lesson 3：觀察光線感應值。繁體中文小組問答遊戲。

## 課堂使用

1. 老師開啟網站並建立房間。
2. 每組用一部 iPad，輸入 6 位房間碼及小組名稱。
3. 老師控制開始、暫停與答案揭曉，各組提交答案。
4. 系統記錄用時、積分和排行榜，完成後老師可下載 CSV。

每題答對 100 分，同分比較答對題目的總用時。最多 8 組，房間有效 24 小時。

## 發布

在 Settings → Pages 選擇 Deploy from a branch，分支 main，資料夾 /(root)，按 Save。

預設網站地址：https://pariswing892.github.io/edu/

## 同步服務

GitHub Pages 提供前端介面。房間、計時、答案及積分由現有已公開服務 https://microbit-sensor-quiz-1005.pariswing892.chatgpt.site 提供。每組及老師都需要網絡連線；用時包含網絡傳送時間。此 GitHub Pages 版無須在前端設定任何私密 API 金鑰。

local.html 是共用一部電腦的投影玩法，可獨立使用。
